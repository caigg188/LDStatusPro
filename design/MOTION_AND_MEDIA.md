# 动效与真实产品展示

目标是让进入、选择和滚动有清楚的空间连续性，同时保持原生滚动、真实界面与流畅操作。参考 Apple 产品页的分层展示、Linear 的界面展示节奏和 [Pure Music](https://qingyueyin.github.io/Pure-music/) 的浅深主题体验；参考体验原则，不复制代码、标志或素材。

## 组件和滚动编排

| 场景 | 已发布实现与规则 |
| --- | --- |
| 首屏进入 | 眉题、逐行标题、说明、按钮和产品画面依次进入；主要使用 `power3.out`，结束后清理内联 transform／opacity |
| 普通内容 | 位移与淡入只进入一次，读过的内容保持可见，不在来回滚动中反复闪烁 |
| 双产品首屏 | 士多窗口由轻微缩小与下移进入平整状态，插件外层完成位置展开 |
| 插件展示 | 浅深面板的外层适度舒展，主题／功能切换保持连续，面板内容来自预渲染图片 |
| 士多展示 | 桌面截图轻微缩放进入，最终保持平面；选择另一截图时淡入 |
| 分段选项 | 指示块滑动，选中状态可读；普通速度约 0.45s，使用连续缓动 |
| 按钮 | hover 轻微上移，按下缩放至约 0.98，普通反馈约 0.25s；触屏无需 hover |
| FAQ | Plus 转动提示开合；原生 details／summary，在支持的浏览器中平滑展开高度，其他浏览器正常折叠 |

当前滚动编排集中在 [useHomepageMotion.ts](../website/src/hooks/useHomepageMotion.ts)，组件反馈在 [brand.css](../website/src/brand.css)。首屏进入通常 0.6–1.05s，段落约 0.85s，滚动 scrub 为 0.45–0.5；这些是当前基线，不把一个时间套给所有动作。

只让展示外层的 transform／opacity 参与主要滚动编排，不旋转截图造成字迹变形，不用动态模糊处理产品画面。页面不接管滚轮、不锁住滚动、不加入长驻循环动画；新增 pin 或重滤镜需要具体体验目的和性能证据，不能仅因“更炫”加入。

滚动和进入动画使用一个作用域，卸载时清理时间线、监听和样式。字体加载后刷新一次滚动位置，图片保留尺寸避免布局跳动。键盘聚焦到文案或动作时立即可见，不等待进入动画。

≤800px 缩小移动幅度。系统开启 `prefers-reduced-motion` 时不创建进入时间线与滚动触发器，CSS 动画／过渡关闭，控件保持可用且内容直接可读。减少动态效果不能造成内容永远透明、按钮无法使用或截图偏出屏幕。

## 插件面板展示

官网必须还原当前插件的原生 UI，不能手画类似仪表盘来替代实际面板。当前 [source.json](assets/product/plugin/source.json) 与 [capture.json](assets/product/plugin/capture.json) 记录脚本版本、源码哈希、演示数据哈希、展示修订和采集方式。

官网可以使用明确标注的模拟登录数据，展示真实使用时的阅读、信任进度和趋势。演示数据不能标成平台实测统计。保留插件原生模板、样式和 Renderer；不要为了装饰添加实际产品不存在的功能。

现行展示采用插件支持的 380px 宽度和 660px 高度上限设置，只显示未完成升级要求，并移除完成度下面的等级徽标以压缩纵向比例。图片为 2 倍采集：升级要求 760 × 1186，趋势 760 × 1211，浅深主题各一份，WebP 质量 96。裁切仅到面板边界，不能拉伸内容。

网站只加载这些 WebP，不嵌入真实插件 iframe，不启动登录、存储、阅读追踪、API、面板运行时、内部动画或滤镜。截图采集 HTML 仅用于离线制作，不作为营销页运行内容。版本由用户脚本 `@version` 注入；更新脚本后重新采集，不能让旧图显示新版本号。

流程按 [官网开发说明](../website/README.md) 执行：生成原生展示 HTML → 检查演示状态与紧凑布局 → 在桌面浏览器以 2 倍比例采集 → 裁切面板边界 → 更新图片与来源哈希 → 构建校验 → 同步 `design` 资产。

## 性能与验收

首页展示必须保持轻量：预渲染图片、明确尺寸、必要预加载与延迟加载，避免图片切换闪白；重页面按路由拆包。当前年报与其 Framer Motion 独立加载，首页使用 GSAP 编排。

验收覆盖进入、往返滚动、主题／趋势切换、士多图库、FAQ、菜单、键盘和减少动态效果；在图片载入前后检查布局稳定。检查插件画面出现时有无明显长任务、掉帧或输入延迟，若发生，优先检查是否误加载插件运行时、循环动画、滤镜和重复监听。不能用一张静态截图宣称已经完成性能测试。
